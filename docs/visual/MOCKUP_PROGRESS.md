## Estado de archivos visuales

- Los PNG generados permanecen adjuntos en el chat.
- El conector GitHub disponible en esta sesión solo permite crear/actualizar archivos UTF-8 mediante Contents API; no admite escritura binaria PNG.
- Por tanto, las capturas quedan pendientes de subida binaria a una carpeta de mockups/capturas en esta misma rama cuando haya una herramienta compatible.
