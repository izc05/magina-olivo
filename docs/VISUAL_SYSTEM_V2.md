# Mágina Olivo — Visual System V2

Esta rama fija la dirección visual oficial previa a implementación.

## Autoridad visual

Cuando una exploración anterior contradiga este documento, prevalece V2.

### Marca
- Logo: rama de olivo + paisaje de Sierra Mágina + gota dorada.
- Claim: `La herramienta digital del olivar`.
- Claim emocional: `De nuestra tierra, lo mejor.`

### Colores
- Verde oliva profundo: `#2E3A22`
- Verde hoja: `#5C7A46`
- Verde salvia: `#A7B497`
- Marfil cálido: `#F4F1E6`
- Oro aceite: `#D4A017`

### Tipografía
- Editorial/marca: Playfair Display o equivalente serif de respaldo.
- Interfaz/datos: Inter.

### Reglas V2
1. Fotografía real del olivar, Mágina, cooperativas y pueblos como protagonista.
2. Fondo marfil; no blanco puro como superficie dominante.
3. Iconos lineales; no emojis en producto final.
4. Tarjetas compactas, bordes finos y sombras suaves.
5. Oro solo como acento.
6. Barra inferior estable: Inicio · Mi Campo · + · Noticias · Mi Mágina.
7. Mapa/parcela ocupa espacio protagonista.
8. La interfaz muestra primero decisiones y estados, después detalle.
9. Un mismo concepto usa el mismo componente en todas las pantallas.
10. La versión web/tablet adapta la app; no crea otro lenguaje visual.

`V2 VISUAL` queda fijada como referencia oficial para implementación.
